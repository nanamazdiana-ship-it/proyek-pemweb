## 1. Deskripsi Proyek
Repositori ini merupakan fondasi awal proyek pengembangan aplikasi berbasis web yang dikerjakan secara berkala (*incremental*) sepanjang semester. Proyek ini ditujukan untuk merancang solusi digital berbasis web yang berfokus pada salah satu bidang studi kasus (Layanan Publik / UMKM / Wilayah Pesisir & Perbatasan / IoT & Dashboard).

*(Catatan: Judul resmi dan spesifikasi studi kasus akan diperbarui setelah penetapan topik akhir).*
